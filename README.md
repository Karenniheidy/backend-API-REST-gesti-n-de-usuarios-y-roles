# Backend API REST - Gestión de usuarios y roles

API REST desarrollada con **Node.js**, **Express** y **MySQL** para la gestión integral de accesos, autenticación y operaciones CRUD en un entorno de desarrollo de software.

## Características principales
* **Autenticación segura:** Registro de usuarios con cifrado de credenciales mediante `bcrypt` y validación de acceso (`login`).
* **Gestión de roles (CRUD):** Creación, lectura, actualización y eliminación de roles técnicos asociados a usuarios.
* **Gestión de usuarios (CRUD):** Administración completa de perfiles de usuario.
* **Base de datos relacional:** Conexión mediante `mysql2` utilizando promesas (`async/await`) y restricciones de integridad referencial (`ON DELETE CASCADE`).
